Sharazan

Самописный модульный бэкенд-фреймворк на Kotlin, вдохновлённый архитектурой Ktor — declare-then-start композиция через Koin, без Spring-магии.

Модули

core

Application bootstrap / composition root: AppBuilder, Lifecycle, обобщённый request/response pipeline.

logging

Общая MDC-вокабулярия и slf4j-зависимости, пробрасываемые транзитивно всем остальным модулям.

http

Coroutine-based HTTP-фреймворк: hand-rolled Netty-транспорт, http4k-типы, роутинг и pipeline из core.

db

Postgres-доступ через Exposed + HikariCP.

security

Hand-rolled, Spring-Security-inspired аутентификация/авторизация: Basic/Form/JWT, сессии, ролевой доступ.

app

Референсное приложение — пример, как эти модули собираются вместе.

Установка

repositories {
    maven { url = uri("https://jitpack.io") }
}

dependencies {
    implementation("com.github.37hulk37:sharazan-core:1.0.0")
    implementation("com.github.37hulk37:sharazan-http:1.0.0")
}
